# CPPkit

Turns your C++ lecture videos into hands-on coding exercises, then reviews the solutions you write for them.

> **This entire project — every line of HTML, CSS, and JavaScript, the Supabase Edge Function, and this README — was generated by AI (Claude). No code in this repository was hand-written by the project owner.**

## What it does

CPPkit is a single-page tool built for studying C++ off lecture videos:

1. **Paste YouTube links** to today's C++ lecture videos (up to 6).
2. It sends each video to an AI model, which summarizes the C++ concepts taught — skipping intros and filler.
3. Those summaries are combined and sent back to the model with a strict instructor prompt, which generates a progressive ladder of 5–12 coding exercises (simple → intermediate → tough), with no code, hints, or solutions included.
4. You write your own `.cpp` solutions, upload them all at once, and the model reviews them against the original exercise text — correctness, missed edge cases, code quality, and the single highest-leverage fix — without ever handing you corrected code.
5. Your links, generated exercises, and review are saved in the browser (`localStorage`) so everything is still there if you close the tab and come back. A **Reset** button clears it.

## How it's built

- **Frontend:** one static `cppkit.html` file — no build step, no framework, no dependencies. Open it directly in a browser.
- **AI calls:** proxied through a Supabase Edge Function (`gemini-proxy`) so the API key never reaches the browser. The frontend calls the function; the function calls the model and returns just the text.
- **Model fallback:** the Edge Function tries a primary model first and automatically falls back to a secondary one if the first fails.
- **Storage:** `localStorage` in the browser, no backend database involved for user data.

## Setup

1. Deploy the `gemini-proxy` Edge Function to a Supabase project.
2. Set a `GEMINI_API_KEY` secret on that function (Supabase dashboard → Edge Functions → Secrets, or `supabase secrets set GEMINI_API_KEY=your_key --project-ref <project-ref>`).
3. Update `PROXY_URL` in `cppkit.html` to point at your deployed function's URL.
4. Open `cppkit.html` in a browser. Nothing else to install.

## Notes

- The Edge Function currently accepts requests without authentication (`verify_jwt: false`) so a plain local HTML file can call it. This keeps the API key private, but the function's URL itself is callable by anyone who has it — fine for personal use, worth adding a shared-secret check before sharing the tool more widely.
- This is a personal study tool, not a polished product — built and iterated on entirely through conversation with Claude, prompt by prompt.
